# v5_sweep_priority_gate

We were testing whether two measured changes would improve the real five-minute training gate: separate cooperative-sweep launch grids (four blocks per SM for backpropagation and two for reach), and a high-priority CUDA stream for fitting the value network. The run initialized from `v5_lane_whale_25m_learning/snap_01.pt` and skipped the Greedy warmup so that all five minutes exercised ReBeL generation and training.

The result was a clear failure. The run completed 147,681 solves and 589,824 optimizer rows in 307.2 seconds, for 479.9 balanced solves/s including drain. Admission stopped at 280 seconds; immediately before that, the cumulative rate was 526/s. There were zero drops and zero exact CPU fallbacks, and training stayed caught up until the final 900-row partial batch. The opening briefly reached 1,498/s, but the recent rate fell to roughly 300--400/s as the actors reached more expensive positions. Only 453 games finished, with the first completions appearing in the 100--110 second report, versus about 62 seconds after the Greedy warmup in the earlier strong-initializer gate.

This run does not isolate the sweep-grid change from stream priority, but the grid caps had already improved an identical frozen workload by about 10%. The high-priority training stream is therefore the leading suspect: it achieved perfect training debt by preempting solve work on GPU 1, which is the opposite tradeoff needed here. A normal-priority run with the same initializer and no warmup is required before attributing the entire gap to it. Average utilization was 58.0% on GPU 0 and 57.2% on GPU 1; peak memory was 17,473 MiB and 16,475 MiB. The run used fast FP16-input/FP32-accumulate GEMMs and the giant-wave memory fix.

At this point the production engine still passes the precise FP32 CPU oracle, the exact zero-network oracle, probability and finiteness checks, and exact buffer-reuse checks. Fast tensor-core mode uses measured error bounds because iterative regret matching can amplify small leaf-value rounding on synthetic random weights. The earlier checkpoint ladder still establishes that `snap_01.pt` learned: it beat Greedy 26--3 and its own initializer 24--2 in paired games.
